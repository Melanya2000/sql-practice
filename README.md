# SQL Practice

My solutions to 29 SQL challenges from the Data Analytics course at Armenian Code Academy (Module 3: SQL with MS SQL Server).

All queries are written in T-SQL and use the Microsoft sample databases **Northwind** and **pubs**.

## Topics

- Aggregation: `GROUP BY`, `HAVING`, `CASE`, `COALESCE`, `CAST` / `CONVERT`
- Joins across multiple tables
- Subqueries and derived tables, `NOT IN` vs `NOT EXISTS`
- CTEs
- Window functions: `LAG`, running totals, moving averages, `PERCENT_RANK`, cohort retention

## How to run

1. Install SQL Server and SSMS.
2. Install the sample databases: [northwind-pubs](https://github.com/microsoft/sql-server-samples/tree/master/samples/databases/northwind-pubs).
3. Open `SQL_practice.sql` in SSMS. Each challenge starts with `USE Northwind;` or `USE pubs;`..
